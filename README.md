# NPKV - AI & ML Developer Portfolio

Welcome to the source code for my personal portfolio! This is an immersive, highly interactive Single-Page Application (SPA) designed to showcase my projects in Artificial Intelligence, Machine Learning, and Software Engineering.

## 🚀 Features

- **Interactive Neural Network Background**: A dynamic HTML5 Canvas background where glowing nodes float, connect with each other, and interact with the user's mouse cursor.
- **Glassmorphism Aesthetic**: Sleek, futuristic UI featuring frosted glass cards, neon accents, and smooth transitions.
- **Scroll Reveal Animations**: Elements fade and glide into view dynamically as you scroll down the page.
- **Responsive Design**: Fully responsive layout that adapts beautifully to mobile, tablet, and desktop screens.
- **Project Showcase**: Detailed cards for all my core GitHub projects including *Titanplus AI*, *Virtual SOC Agent*, *EarthData*, *Exoplanet Hunting*, *Fashion Classification*, and *Agentic-Auditor*.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and modern markup.
- **CSS3 (Vanilla)**: Advanced styling using CSS variables, Flexbox, Grid, animations, and glassmorphism (backdrop-filter).
- **JavaScript (Vanilla)**: Intersection Observers for scroll animations and Canvas API for the interactive neural network background.

## 🚦 How to Run Locally

Since this is a static website, you can simply open `index.html` in your web browser. However, for the best experience (especially for local assets to load properly), run a local HTTP server:

```bash
# Using Python 3
python -m http.server 8000
```

Then, open your browser and navigate to:
`http://localhost:8000`

## 📁 Repository Structure

- `index.html`: The main entry point containing all sections (Hero, About, Skills, Projects, Certifications, Contact).
- `style.css`: The stylesheet defining the dark theme, neon glow, typography, and responsive layouts.
- `script.js`: The JavaScript file powering the background canvas animation and the scroll-reveal observers.
